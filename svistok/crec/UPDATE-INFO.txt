CREC UPDATE 0.1.3.9

BASE COMPATIBILITY: 0.1.1.1 and later
TARGET: 0.1.3.9
DEPLOY ROOT: /crec/

Исправление 0.1.3.9:
- Найдена точная причина неподвижного сушибелта: CSS-правило transform:none!important блокировало transform, который JavaScript менял каждый кадр.
- Конфликтующее правило удалено.
- JavaScript теперь задаёт движение ленты через transform с приоритетом important, чтобы другие старые стили не могли снова остановить ленту.
- Скорость движения увеличена до явно заметной плавной прокрутки.
- Переключатель «Приостановить / Продолжить движение» сохранён.
- Смена фотографий внутри карточек сохранена.
- Версия кэша синхронизирована: 20260918.10.

Пакет кумулятивный и включает все предыдущие исправления 0.1.3.x.
Удалений файлов нет.
