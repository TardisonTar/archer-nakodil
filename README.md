# Archer Nakodil

Репозиторий разделён на три верхнеуровневые категории:

- `stable/` — стабильная версия портала и игр.
- `test/` — тестовая версия портала и игр.
- `svistok/` — отдельная категория проектов «Свисток».

## STABLE и TEST

В обеих категориях:

- `portal/` — портал / основной сайт Archer Nakodil.
- `games/site/` — игры, запускаемые на сайте:
  - `morskoy-boy/`
  - `tetris/`
- `games/pc/` — игры для ПК.

## СВИСТОК

- `svistok/crec/` — КРЭК.
- `svistok/dom-svistka/` — Дом Свистка.

КРЭК и Дом Свистка не входят в `stable/` и `test/`.
