# Archer Nakodil 2.0

Исходный репозиторий портала **Archer Nakodil v2.0**.

## Что входит

- портал Archer Nakodil;
- Морской бой 1.4.2 с запуском с собственного хостинга;
- Дом Свистка 3D;
- Тетрис;
- CREC/КРЭК;
- архивная итерация CREC Radio Assembly;
- карточка пиксельного платформера;
- каталог релизов, PWA, changelog, статус-проекты;
- API мониторинга/аналитики;
- Nginx/systemd инфраструктура;
- GitHub Actions для проверки и деплоя.
