# Archer Nakodil

Репозиторий разделён на две независимые категории:

- `stable/` — стабильная версия.
- `test/` — тестовая версия.

В каждой категории одинаковая структура:

- `portal/` — портал / основной сайт Archer Nakodil.
- `games/site/` — игры, запускаемые на сайте:
  - `morskoy-boy/`
  - `tetris/`
- `games/pc/` — игры для ПК.
- `crec/` — проект КРЭК.
- `dom-svistka/` — Дом Свистка.

Тестовая и стабильная категории не смешиваются.
