КАК ИГРАТЬ

Точность решает.

  1. У каждого игрока 10 кораблей: один на 4 клетки, два на 3, три на 2 и четыре на 1.
  2. Корабли стоят горизонтально или вертикально и не касаются друг друга, даже углами.
  3. Нажимайте на клетки поля противника. При попадании стреляйте ещё раз; при промахе ход переходит сопернику.
  4. Когда корабль потоплен, клетки вокруг него отмечаются автоматически.
  5. Потопите весь флот противника первым, чтобы победить.

При ручной расстановке выберите длину корабля и нажмите на своё поле. Нажатие на поставленный корабль убирает его. Поворот — кнопка или R. По полям можно перемещаться стрелками, действие — Enter.

    ИГРА ПО ЛОКАЛЬНОЙ СЕТИ

    Каждому — свой экран.

    Один компьютер запускает сервер. Второй игрок открывает его адрес в браузере на компьютере, планшете или телефоне.

    1. Скачайте и полностью распакуйте комплект для локальной сети.
    2. На компьютере с Python 3 запустите START-WINDOWS.bat или файл запуска для своей системы.
    3. Оба игрока открывают адрес из окна сервера. Один создаёт комнату, второй вводит её код.

    Для двух устройств используйте комплект «Морской-бой-LAN.zip», который можно скачать из меню сайта вместе с этой игрой.

    Интернет не нужен. Окно сервера должно оставаться открытым. Python нужен только на компьютере, запускающем сервер.

    Создайте комнату и передайте другу адрес сервера и код. Оба устройства должны быть в одной сети.
