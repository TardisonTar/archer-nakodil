# /api — зарезервировано для серверных функций

Папка создана в соответствии со структурой портала Archer Nakodil. Сейчас сайт статический.

В дальнейшем сюда/за этот URL можно направить reverse proxy для:
- информации о версиях;
- статистики загрузок;
- серверных функций игр;
- health-check.

`health.json` — только статический маркер структуры, не полноценный API endpoint.
